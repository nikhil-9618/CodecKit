CodecKit

The developer & cybersecurity toolkit. 🔒 Most processing runs in your browser. Password breach and CVE lookups connect to public APIs. No application backend, no ads. Optional lookup tools make requests to public APIs.

⇄ Encoding & Decoding

  • Base64UTF-8 safe encode & decode, file→data URI
  • Base64URLJWT's URL-safe alphabet
  • Base32RFC 4648, TOTP secret keys
  • Base58Bitcoin alphabet, no 0/O/I/l
  • URL EncodePercent-encoding for query strings
  • HexText ↔ hexadecimal bytes
  • BinaryText ↔ 01001000-style groups
  • ROT13Self-inverse letter obfuscation
  • CaesarShift 1–25 with live slider
  • MorseInternational Morse code
  • Bacon5-symbol a/b cipher groups
  • HTML Entity&escape; <tags> safely
  • Unicode Escape\uXXXX sequences
  • JWT DecoderPeek inside tokens, human dates

🛡 Security & Analysis

  • Password StrengthEntropy + breach check via k-anonymity
  • Hash GeneratorMD5, SHA-1/256/384/512
  • Hash IdentifierGuess MD5/SHA/bcrypt/Argon2 from shape
  • Subnet CalculatorCIDR math with step-by-step binary
  • CVE ExplainerPlain-English vulnerability summaries
  • JWT SignerHS256 locally, testing only

🛠 Developer Utilities

  • Timestamp ConverterEpoch ↔ ISO 8601, live clock
  • Regex TesterLive matches + capture groups
  • Diff CheckerLine-by-line LCS comparison
  • Explain CommandFlag-by-flag shell breakdown
