About CodecKit

CodecKit exists because every other "toolkit" site greets you with ads, cookie popups and a JS bundle from 2013. This one is a handful of HTML, CSS and vanilla ES2022 modules that does conversions in your browser.

The privacy promise

  • No accounts, no logins, no sessions.
  • No analytics, no trackers, no cookies. No cookie banner needed — there is nothing to consent to.
  • Most inputs stay in your browser. The following features make external requests:
    1. Password breach check uses HIBP k-anonymity — only the first 5 hex chars of a local SHA-1 are sent; the full hash and password stay local.
    2. CVE lookup sends the CVE ID — which is public information anyway — to the NVD API.
  • Everything else (JWT secrets, hashes, diffs, your last 10 inputs per tool) lives in localStorage on your device.
  • The service worker caches the app so it keeps working offline.

Feedback & contributions

CodecKit is open source (MIT). Ideas, bugs and pull requests are welcome — see CONTRIBUTING.md in the repository. Adding a codec is one file + one registry line.
